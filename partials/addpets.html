        Restrictions:

        1. Don't use a header for CSV file.
        2. Name: must start with a capital letter, contain only letters and spaces, and be 2..15 characters long.
        3. Birth Date: must be a date from past(format: YYYY-MM-DD).
        4. Species: must start with a capital letter, contain only letters and spaces, and be 2..15 characters long.
        5. Breed: must start with a capital letter, contain only letters and spaces, and be 2..15 characters long.
        6. Health Status: must be one from [healthy, injured, sick].
        7. Region: must be one from [Botosani, Bacau, Galati, Iasi, Neamt, Suceava].
        8. Pickup Address: must start with a capital letter, contain only letters and spaces, and be 4..40 characters long.
        9. Group: must be one from [0, 1].
